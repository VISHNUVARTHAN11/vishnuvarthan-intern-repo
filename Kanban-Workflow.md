# Agile Workflows & Kanban

## What is a Kanban board?

A Kanban board is a simple visual way of managing work. It helps me see what tasks I need to do, what I am currently working on, and what has already been completed.

For my internship repo, I set up the following workflow:

- **Not Started** – Tasks that I have not started yet.
- **In Progress** – Tasks that I am currently working on.
- **Ready for Review** – Work that I have completed and is ready to be checked.
- **Approved by Bot** – Work that has passed the required automated review or bot check.
- **Done** – Tasks that have been fully completed.

## How tasks move through the board

A task starts in **Not Started**. When I begin working on it, I move it to **In Progress**.

Once I have completed the required work, I move it to **Ready for Review**. After the required review or automated check, it can move to **Approved by Bot**, and then to **Done** when everything is complete.

Keeping the status updated means the team can quickly see where each task is without needing to ask for an update.

## Why limit Work in Progress (WIP)?

Limiting WIP means avoiding having too many tasks open at the same time.

If I start too many things at once, it becomes harder to concentrate and easier to leave several tasks unfinished. Keeping fewer tasks in progress helps me focus on finishing what I have started before taking on another task.

It also makes blockers easier to notice because I can clearly see which task is currently stopping progress.

## Reflection: priorities and avoiding overload

Kanban helps me manage priorities because I can see all my tasks in one place. Instead of trying to work on everything at once, I can focus on the tasks that need attention first.

It also helps me avoid overloading myself. If I already have several tasks in **In Progress**, I should finish one of them before moving another task into that column.

## How I can improve my workflow

I can improve my workflow by keeping the board updated whenever the status of a task changes.

I can also break larger tasks into smaller steps and check the board at the beginning and end of each work session. This gives me a clearer idea of what I should work on next.

Another useful habit would be to leave a short update when moving a task between stages. For example, when moving a task to **Ready for Review**, I can mention what I completed and whether there are any issues or questions.

**Not Started → In Progress → Ready for Review → Approved by Bot → Done**

Using Kanban gives me a simple way to organise my internship work and see my progress.

I think keeping the board updated and limiting the number of tasks I work on at the same time will help me stay organised, avoid taking on too much work, and make my progress easier for the team to follow.
