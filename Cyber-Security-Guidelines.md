# Cyber Security Guidelines

## Common cyber security threats when working remotely

Working remotely can introduce several security risks. Some common threats include phishing emails, suspicious links, malware, weak passwords, stolen devices and using unsecured public Wi-Fi.

Phishing is particularly important because an attacker may try to make a message look like it came from a trusted person or company. They may ask for login details, payment information or access to an account.

## Best practices for keeping devices and accounts secure

Some basic practices I should follow are:

- Use strong and unique passwords for important accounts.
- Enable two-factor authentication (2FA) wherever it is available.
- Keep Windows, mobile devices, browsers and applications updated.
- Use a trusted password manager instead of reusing passwords.
- Avoid clicking suspicious links or opening unexpected attachments.
- Lock my computer whenever I step away from my desk.
- Avoid using sensitive company information on unsecured public networks.
- Only install software from trusted sources.
- Be careful about what information I share through email, Discord and other communication platforms.

## Why locking my computer is important

Locking my computer when I step away prevents someone else from accessing my accounts or information if they get physical access to my device.

Even if I am only away for a few minutes, leaving the computer unlocked could allow another person to view files, messages or accounts that are already signed in.

## How I should handle phishing and suspicious links

If I receive a suspicious email or message, I should not immediately click the link or download an attachment.

I should check the sender and the context of the message carefully. If something seems unusual, I should verify it through another trusted method instead of replying directly.

If I believe a message is a phishing attempt, I should report it through the appropriate company or platform process and remove it rather than interacting with it.

I should also never enter my password or other sensitive information into a website just because a message tells me to do so.

## Strong passwords and password managers

A strong password should be long, difficult to guess and unique to the account. Reusing the same password across multiple accounts is risky because if one account is compromised, other accounts using the same password could also be affected.

A password manager can help generate and store unique passwords, which means I do not have to remember every password myself.

I should never store company passwords in plain text files, screenshots, notes or chat messages.

## Why two-factor authentication is important

Two-factor authentication provides an additional layer of protection when logging into an account.

With 2FA enabled, knowing the password alone is not normally enough to access the account. An attacker would also need the second authentication factor.

I should enable 2FA on my work accounts and other important accounts whenever it is available.

## My current security habits

I already try to be careful about suspicious messages and links, and I understand that passwords should not be shared with other people.

I also understand the importance of keeping my computer and software updated.

One area I can improve is being more consistent about checking that 2FA is enabled on all important accounts and making sure my devices automatically lock when I step away.

## How I can make secure behaviour a habit

I think security is easier to maintain when it becomes part of my normal routine instead of something I only think about after a problem happens.

For example, I can make checking for software updates, reviewing account security settings and locking my computer part of my regular work routine.

I can also pause before clicking links or opening attachments and ask myself whether I expected the message and whether the request makes sense.

## Password and account security

For my important accounts, I will use unique passwords and enable 2FA wherever possible.

I will avoid reusing passwords between accounts and will use a password manager to securely manage my credentials.

I will also make sure I do not share passwords, authentication codes or other sensitive information through email, Discord or other communication channels.

## What I would do if I suspected a security breach

If I suspected that one of my work accounts had been compromised, I would act quickly rather than ignoring it.

I would stop interacting with anything suspicious, secure the affected account, change the password if appropriate, and check for unusual account activity.

I would then report the suspected incident to the appropriate Focus Bear team member and follow the company's security process.

I would not try to hide the incident because reporting it quickly could help reduce the impact.

## My new cyber security habit

My new cyber security habit at Focus Bear will be:

**Before starting work, I will check that my computer is locked when I step away and I will pause before opening unexpected links or attachments. I will also regularly check that 2FA is enabled on my important work accounts.**

This is a small habit, but doing it consistently should help me make security part of my normal working routine rather than an afterthought.

## Conclusion

Cyber security is everyone's responsibility, especially when working remotely.

By using strong and unique passwords, enabling 2FA, keeping devices updated, locking my computer, being careful with links and reporting suspicious activity, I can reduce the risk of security problems and help protect both company and user information.
